# Timeline Restorer: Back in Time — Version 1

Preserved 2026-11-11. This is the original release of the game: a single
self-contained HTML5 file (`timeline-restorer.html`, 2,346 lines, 183 KB)
with zero external dependencies.

- 5 acts (Philadelphia 1764, Manchester 1830s, Europe 1690s, airfield 1912,
  Temporal Core)
- Point-and-click investigation, Truth Verification Engine, inventory
  puzzles and combining, branching dialogue, paradox/stability system
  with ripple effects, per-act quizzes, 4 endings, ranks S–D
- Save/load via localStorage, debug console (Ctrl+Shift+D), Web Audio bleeps

## How to play

Open `timeline-restorer.html` directly in Chrome, Edge, Safari or Firefox.
No server, no install, no internet needed.
